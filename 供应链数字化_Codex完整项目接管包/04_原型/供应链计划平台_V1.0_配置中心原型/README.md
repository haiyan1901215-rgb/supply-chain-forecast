# 供应链计划平台 V1.0：配置中心原型

## 原型目标

本版本把《商品标签配置表.xlsx》中的业务规则拆解为可维护、可版本化、可供数仓读取的配置中心原型。

目标链路：

```text
业务规则配置
→ 数仓读取配置
→ 数据清洗
→ 规则计算
→ 商品标签
→ 销量预测
→ 需求缺口
→ 采购计划
→ AMZ过货/调拨计划
```

本版本不设计销量预测算法平台，也不把销售填报、PMC审核、采购预下单等业务操作做成基础配置。

## 配置边界

原型严格区分三类内容。

### 系统配置

业务人员维护规则、参数、阈值、系数、映射关系和策略。例如生命周期天数、价值分档阈值、趋势阈值、季节指数、Listing适配系数、动态α、ADU初始化参数、SKU版本关系、MOQ、备货水位、物流时效、起运量和共享渠道。

### 数仓计算结果

数仓根据配置和业务数据计算，不允许业务在配置中心维护。例如近3/7/30天销量、TrendRate、ADU0、父体ADU、子体ADU、需求缺口、DOI、实际销量和预测销量。

### 业务操作结果

属于业务流程，不进入基础配置中心。例如销售人工预测、人工纠偏、PMC审核、采购预下单和本次下单备注。

## 计划参数：销售预测周期

PMC的本期预测任务入口放在：

```text
计划配置 → 计划参数 → 销售预测周期
```

已实现交互：

- 发起本期预测：Drawer三步流程，选择预测月份、需维护W周期数、填报窗口并确认发起。
- W周期联动：根据计划日历自动生成W1-W6日期，PMC只选择需维护周期数，不手工维护日期。
- 确认发起：Mock状态改为「销售填报中」，填报进度和W周期进度初始化为0%。
- 调整截止时间：Drawer修改截止时间并实时更新页面。
- 关闭销售填报：Modal确认后状态改为「销售填报已关闭」。
- 进入审核：关闭后进入PMC审核流程。

同一预测周期已发起后，不允许重复创建新的本期预测任务。

## 关键业务规则处理

### 商品标签规则

已结构化生命周期、价值分档、归集价值分档、近期趋势、采购属性、预测分流和过货标签。

其中：

- IPD项目款不强行塞入生命周期天数规则。
- AMZ-US、AMZ-UK、AMZ-EU价值分档阈值按渠道/站点配置，不写死在前端。
- A/B/C完整阈值不足的内容标识为「原型示例」或「待确认规则」。
- 归集后二次判断「日销<20强制F退市」标识为「原型假设 / 待确认规则」。
- TrendRate本身不进入配置，只配置增长、平稳、衰退的判定阈值。

### 预测规则

已结构化季节指数、Listing适配系数、动态α和ADU初始化参数。

其中：

- SeasonFactor是数仓计算结果，配置中心只维护每月季节指数。
- Listing适配系数按渠道、国家/站点、父体ASIN、BSR区间和销量分层配置。
- 动态α维护TrendRate区间到α的映射。
- ADU初始化维护全窗、近期窗、权重、有效日定义和回退规则。

### 商品映射

已结构化父子ASIN映射、父体变更关系、SKU版本关系和商品基础信息。

其中：

- 首版SKU作为库存和销量归集的核心匹配键。
- 父体变更关系用于把后继父ASIN映射回首次父ASIN。
- 差评移除不计入父体变更关系。

### 备货策略和物流策略

已结构化采购基础参数、MOQ规则、备货水位、需求覆盖、共享渠道、物流时效、起运量和入库规则。

其中：

- MOQ支持SKU MOQ、SKC MOQ和供应商组MOQ。
- 备货水位标识为「当前业务参数」，不固化为永久规则。
- 物流时效包含仓库作业时效、AMP快船、STA快船、STA普空、STA快空等当前业务参数。
- 入库倍数等口径标识为当前业务参数或待确认规则。

## 保留内容

V1.0基于V0.9复制生成，保留原销售预测页面的核心可操作原型能力：

- 销售预测页面不放PMC发起/关闭入口。
- 销售运营通过W周期Tab维护当前W周期销量预测。
- 历史销量、库存/在途、AI预测通过Popover查看。
- 商品完整信息通过Drawer查看。
- 预测值修改要求填写调整原因。
- PMC审核、退回和销售重新提交仍保留在销售预测业务流程中。
