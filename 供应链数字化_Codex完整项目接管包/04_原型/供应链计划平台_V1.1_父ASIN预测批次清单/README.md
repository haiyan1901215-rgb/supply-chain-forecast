# 供应链计划平台 V1.1：父ASIN预测批次清单

## 本版范围

计划配置入口先显示预测批次。打开批次后，在父ASIN清单内查看预测依据、关系快照、子ASIN份额和库存，并完成本批次校准及销售组合拆解。商品标签、Clean ADU、趋势、季节指数和库存指标作为系统结果只读展示；PMC覆盖只作用于当前批次并记录原因。

销售预测填报页面直接沿用V1.0原型文件，未调整其页面、字段和交互。

## 数据样例口径

- 父体标签样例：使用附件中的 UK / B01NAK65YI 记录，保留父级ADU、窗口、动态α、趋势、价值、季节、毛利和BSR字段。
- 子体预测样例：使用附件中 UK / B01NAK65YI 的6条记录，以及 US / B07HQGX677 的2条记录，保留份额、ADU、90天预测量、FBA库存、在途和库存标签。
- 两份结果文件的截点为2026/07/31，早于示例批次的2026/10/21；原型明确提示这批源样例不可当作新批次计算结果。
- US / B07HQGX677 在父体标签文件中没有对应行，详情提供“确认采用子体汇总为本批次基线”的带原因操作。
- 季节指数库作为计算规则来源展示，不做每批次维护页面。附件没有销售组合关系表，因此组合SKU只用用户给出的结构示例，并标注待主数据确认。
- 批次清单中的规模数字是用户提供的界面示例；清单中的商品明细使用附件真实样例。

## 交互

- 批次搜索、创建、打开与返回。
- 父ASIN展开、关键异常筛选、国家和商品搜索。
- 父体ADU调整、计算依据展开、参数局部覆盖、关系变更记录。
- 子体份额单条调整及批量调整；调整时对其余子体按剩余比例重新分配。
- 当前清单份额归一、组合拆解比例校验、销售提交前检查与操作记录。

页面运行方式：浏览器直接打开 `index.html`。
