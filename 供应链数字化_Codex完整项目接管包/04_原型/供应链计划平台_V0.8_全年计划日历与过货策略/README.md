# 供应链计划平台 V0.8：全年计划日历与过货策略

本版本基于 V0.7 继续迭代，保留五个业务入口：销售预测、备货计划、调拨计划、货权归属、计划配置。

## 本轮新增

- 计划日历补全为 2026 全年 365 天。
- 业务计划周改为年度连续周：2026/01/01-2026/01/07 为 W1，2026/12/31 为 W53。
- 计划日历支持月份筛选、W1-W53 周筛选、列表视图、月度视图、生成、导入、编辑。
- 新增「计划配置 → 过货策略」，未新增“过货参数”“物流参数”“渠道策略”等菜单。
- 过货策略内部使用页签：策略规则、时效参数、版本记录。
- 策略规则支持列表视图和策略矩阵视图。
- 策略规则内置 B店 / US 示例数据，但 B店、US、水位天数均作为可配置字段展示。
- 新增策略 Drawer 支持重复规则校验。
- 调整策略 Drawer 保留当前版本，创建新目标水位、新生效时间和变更原因。
- 停用策略使用二次确认，不影响历史计划数据。
- 版本记录展示旧值、新值、生效时间、变更原因、操作人和操作时间。

## 界面规范

- 页面结构统一为：标题、搜索区、功能按钮区、列表区、右下分页。
- 各列表均含复选框列。
- 不展示工作台、商品计划、数据中心菜单。
- 不展示原型边界、说明性提示语和统计卡片。
- 表格不固定列，保留普通横向滚动。
- 计划配置使用页签承载配置对象，避免把流程节点或参数对象继续扩展成菜单。

## 运行

在本目录执行：

```bash
python3 -m http.server 8790 --bind 127.0.0.1
```

访问：

```text
http://127.0.0.1:8790/
```

本版本为静态业务验证原型，未引入新的 UI 框架或构建依赖。
