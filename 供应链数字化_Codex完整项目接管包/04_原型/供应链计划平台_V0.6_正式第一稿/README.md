# 供应链计划平台 V0.6

这是供应链计划平台 0→1 正式第一稿的业务验证型原型。原型采用纯 HTML/CSS/JavaScript，可直接打开 `index.html`，也可以从本目录启动静态服务。

## 已实现

- 统一计划平台导航：销售预测、备货计划、调拨计划、货权归属、计划配置；工作台、商品计划、数据中心不作为本版菜单入口。
- 销售预测列表：待审核/退回/确认状态页签、关键词筛选、更多筛选、分组表头、30 条真实语境 Mock 数据、复选框列、可操作分页和批量选择；宽表仅保留普通横向滚动，不固定任何表头或数据列。
- 销售填报：销售最终预测行内编辑；与 AI 最终预测不一致时必须填写调整原因；保存后保留 AI 值、销售值、调整量、原因和操作记录。
- 销售预测周期：PMC 可在“销售预测”中开启月度填报窗口，配置预测月份、填报对象、PMC 负责人、开始/截止时间、时区和截止后处理方式，并通过确认页生成“填报中”周期；已开启周期支持延长窗口。
- AI 预测解释：基础日均、趋势修正、季节修正、活动增量、数据周期和预测版本抽屉。
- PMC 审核链路入口：批量提交审核、状态变化、退回原因校验、工作台待办跳转。
- 备货计划：以计划批次承载需求输入、系统计算、PMC确认、采购反馈和计划定稿；展示需求、库存/在途扣减、原始缺口、MOQ、建议采购量、供应商、交期和状态。
- MOQ 异常：延长备货周期、跨渠道合并、接受 MOQ 放大、销售确认四种处理方式及必选校验。
- 备货计划详情内提供供应反馈和采购需求输出衔接，采购反馈包含 MOQ、交期、无法供应、拆单、换供应商等选项。
- 调拨计划：合并 FBA 过货与调拨执行，展示销售需求、FBA 库存/在途、计划调拨量和执行状态。
- 货权归属：按月份维护库存与在途货权分配及确认状态。
- 计划配置：通过页签维护计划规则、计划日历、供应商、物流、MOQ 和渠道策略；计划日历支持年度/月度筛选、日期/月份/业务计划周列表、W5 跨月末日期展示、月度视图、生成、导入和编辑。

## 本轮界面规范调整

- 侧栏只保留业务导航，不展示原型边界、版本或演示说明。
- 所有列表统一补充复选框列，功能按钮统一靠左，分页统一靠右下方。
- 页面移除说明性副标题、提示块和计划上下文卡片，优先呈现筛选区、操作区和列表。
- 所有表格取消冻结表头和冻结列，保留必要的普通横向滚动。
- 计划日历中的 W1/W2/W3/W4/W5 按“每月 1 号起每 7 天划分一周”的业务计划周规则生成，不使用 ISO 自然周定义。

## 本轮导航与页面密度调整

- 主导航收敛为五个业务入口：销售预测、备货计划、调拨计划、货权归属、计划配置。
- 业务节点、数据基础和配置项通过状态页签、流程步骤、详情抽屉和配置页签承载，不再拆分为独立菜单。
- 扫描菜单页面并移除统计卡片，页面结构统一收敛为筛选区、功能操作区和列表区；所有列表带复选框列和右下分页。

## 业务边界

库存事实、销量预测算法、供应商主数据、正式 PR/PO 创建系统、采购反馈后的自动重算、统一备货天数和统一 MOQ/物流时效均以示例配置或待确认方式表达，原型不把它们宣称为最终规则。

## 运行

直接打开 `index.html` 即可预览。需要本地服务时，在本目录执行：

```bash
python3 -m http.server 8788 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8788/`。

本版本是静态验证型原型，不引入新的 UI 框架或构建依赖；视觉和交互按 Ant Design 企业后台规范组织，下一阶段可在确定技术栈后迁移到现有前端工程。
