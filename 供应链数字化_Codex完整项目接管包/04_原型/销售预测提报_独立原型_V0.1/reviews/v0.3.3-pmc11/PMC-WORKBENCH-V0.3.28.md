## 页面职责与实现

| 项目 | PMC预测批次详情 | 销售预测填报 |
| --- | --- | --- |
| 预测线 | 系统预测、PMC基准、最终预览 | 系统预测、只读PMC基准、人工预测、活动预测、最终预测 |
| 校准 | ADU/比例弹窗、必填原因、恢复、调整前后ADU审计 | 只读PMC结果，沿用原人工/活动原位编辑 |
| 父子关系 | 当前批次维护、原父体/新父体及调整原因 | 从发布快照构建树，跟随批次关系 |
| 子体份额 | 一处最终占比、行内编辑、100%校验、归一化、恢复系统占比 | 读取拆分结果 |
| 组合拆解 | 仅组合对象提供维护入口，沿用数量比例与整数分配 | 读取预测结果 |
| 模型依据 | 点击展开，主表不铺Clean ADU、季节指数等诊断字段 | 只读计算依据 |
| 季节运行 | 引用上游状态/规则版本，未提供值明确提示 | 同步数值或状态文本 |
| F10等待 | null数值与“人工启动（待实际销量）”状态分离；等待日期不能校准 | 等待日期不能填写人工/活动；不作为0参与数值汇总 |
| 筛选 | 母版筛选增加层级、配置状态 | 保留现有筛选 |
| 时间轴 | W周、14/30天、星期、日预测/周汇总、横向滚动 | 保留现有W周与日级交互 |
| 准备度 | 校验项、异常数及定位到行 | 读取已发布批次 |
| 参数 | 弹窗提交，明确次日/后续批次生效 | 仅显示绑定版本 |
| 重新计算 | 确认后重建演示结果快照，保留PMC校准/关系/销售草稿 | 不提供此入口 |
| 发布/冻结 | 发布锁定基线和关系；不可变快照进入销售 | 保留填报窗口与流程控制 |

## 共用边界

- 沿用销售自定义 `.forecast-table` 样式、固定列和表头约定、现有图标及行列高亮。固定宽度仍为40/334/60/190/130px，不通过新增覆盖样式重新设计。
- 新增 `forecast-ledger-values.js`，两端共用预测线定义、数值/状态识别与汇总语义；`ForecastBatchContract`承载系统值、PMC基准、版本、关系和状态。
- React PMC工作区与原生销售页仍保留各自渲染适配入口；本版没有将整个商品信息/表格DOM重写成单个JavaScript renderer，也不作该项已完成的声明。
- 遵循企业设计技能：新增表单/弹层使用既有Ant组件与主题；用户指定的销售自定义台账优先保留。新增CSS只处理状态文本换行和校准操作间距，未重新设计字体、颜色或销售冻结CSS。

## 接入边界

这是本地内存演示原型，刷新会恢复演示数据；保存调整只保存当前会话草稿。发布是原型内两端读取同一快照，不是生产网络推送。前端角色入口隔离不等于后端权限校验。

未实现新的Clean/EWMA/趋势/季节模型；使用现有示例计算和显式上游结果接口。参数弹窗不承诺修改算法参数后即时重算当前真实批次；真实数仓、规则服务、持久化、权限及发布接口仍需工程接入。

状态示例由测试显式注入，不能从示例F10类型或日期推断业务实际运行状态。历史V0.3.27验证记录保留，新版本记录优先说明本轮授权的销售文件改动。
