## 本轮全局补充对齐

| 检查项 | 处理结果 |
|---|---|
| 商品树展开/收起 | 父体、全部展开、全部收起均使用销售页同源 SVG path，不使用 Ant Table 展开列。 |
| 子ASIN标签 | 直接读取销售页 `tagDefinitions`，标签内容、分类、语义色、字号和圆角逐项比对。 |
| Listing信息 | 子ASIN展示上架日期和距今天数；SKU和业务识别码在商品识别区同时展示。 |
| 编码与上下文分隔 | 父ASIN、SPU/业务码、平台站点、店铺、销售人员统一使用 `丨`，不混用 `/` 作同级编码分隔。 |
| 列宽调节 | 固定信息列和日期列支持指针拖拽及键盘左右键调整，拖动中实时更新表格宽度。 |
| W周表头 | 周头只显示 `Wxx`，不重复日期范围和星期文案；日列默认宽度与销售页统一为 72px，周合计为 112px，预测线右边缘与首个周头、日期列坐标差均为 0。 |
| 预测线展开/收起 | 仅保留表头一个销售页同源 Ant icon；展开为四条预测线，收起为一条最终预测汇总，不再增加子ASIN控制行。 |
| 子ASIN详情操作 | 商品区显示并直接复用销售页的“销售趋势 / 预测分析 / SKU映射”图标、文案和 Drawer 实现。 |
| 台账视图 | 增加 Ant Design 小型 Tabs：仅看子ASIN、仅看父ASIN、变体；默认变体为原父子树，切换只改变行投影，不改变筛选、日期、列宽或批次预测数据。 |
| 父子关系维护 | 树结构只表达关系；行内不再显示“关系待确认”标签或重复关系入口，批量维护收敛为左上功能按键。 |
| 日级预测与历史 | 父子ASIN日预测始终直接显示在右侧时间轴；删除“查看每日预测”和独立“历史”按键，历史对比纳入销量/库存上下文。 |
| 空预测值 | PMC调整、活动预测未填时留白，不用 `-` 或 `—` 占位。 |
| 子ASIN父体占比 | 默认只在商品区保留一处“份额 xx%”可操作入口；预测线不再重复显示，完整计算依据仅在主动展开后呈现。 |
| 右下角分页 | `共 N 条` 紧邻页码之前，仅保留 `20 / 页`、`50 / 页`，不在左侧另放重复统计。 |
| 发布数据合同 | PMC确认后由 `ForecastBatchContract` 生成批次规则预测快照；销售页直接读取同一 child/date 数据，不二次计算。 |

## 代码级隔离修复

- PMC拖拽句柄使用 `data-pmc-resize-column`，避免被销售页全局 `data-resize-column` 捕获器截获；外观、尺寸和键盘行为不变。
- PMC不再生成任何预测线控制行，因此不再需要 `data-forecast-line="pmc-controls"` 隔离协议。
- 修改均仅限 PMC renderer，未改动 `v024-core.js`、`v032-presentation.js`、`v033-controls.js`、`sales-freeze.css` 的销售填报行为。

## 架构硬断言

- PMC 工作台内 `.forecast-table` 数量为 1。
- PMC 工作台内 `.ant-table` 数量为 0。
- `.fp-sales-ledger-table` 和 `.fp-pmc-ledger-table` 数量为 0。
- PMC 主台账实现中不存在 `ant-table-row-expand-icon` 或 Ant fixed-column 依赖。
- 销售预测页面仍由既有 Renderer 负责；PMC 仅共享其表格语义、样式类和交互契约。
