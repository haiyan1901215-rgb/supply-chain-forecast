# V0.3.4 RC1 版本对比与回滚

当前生效：V0.3.3。候选：V0.3.4 RC1。状态：待用户确认。

## 如何对比

打开 http://127.0.0.1:8800/compare-v0.3.4.html ，顶部切换版本。切换保留各自页面的状态；“单独查看此版”可在完整屏幕高度下查看。

建议对比同一商品：查看标题和核心指标层级，点击人工/活动日期格试填，点击外部后重新打开，检查保存后的数值和原因悬停预览。

| 入口 | 用途 | 存储 |
| --- | --- | --- |
| `/` | 当前使用版V0.3.3 | 原存储键 |
| `/reviews/v0.3.3/index.html` | 外观不变的独立对照预览 | `pmc-review-v033:` |
| `/candidates/v0.3.4-rc1/index.html` | 候选预览 | `pmc-candidate-v034rc1:` |
| `/releases/v0.3.3/` | 冻结原资源，用于恢复 | 原存储键，不作为试填入口 |

预览首次打开时复制当前已保存的预测、备注、列配置及列宽，此后不再同步。两版的试填不会改动当前版，不会互相覆盖；正式切换不导入预览试填数据。仍是本地Mock原型，无后端版本服务。

## 确认规则

- 用户选择保留V0.3.3：无需任何切换，继续使用原入口。
- 用户明确接受候选版后：才执行正式切换，使用原来的业务数据键。
- 生效后若需要回滚：恢复V0.3.3冻结入口，原数据保留，不执行数据清空。本轮未变更数据结构，已保存预测仍可被旧版读取。

## 维护命令

在本目录执行（`node`可换为环境Node的绝对路径）：

```sh
node tools/version-manager.mjs status
node tools/version-manager.mjs verify
node tools/version-manager.mjs activate
node tools/version-manager.mjs rollback
```

`activate` / `rollback` 不带参数均仅预演。只有用户在对话中明确确认后，维护者才可执行对应命令并附加 `--user-approved`。工具不验证聊天授权，参数不能替代真实批准。

切换生成独立正式发布目录，再替换根入口；回滚从SHA-256校验通过的V0.3.3快照恢复根入口。候选目录损坏不会阻止回滚。每次执行后再次检查`versions.json`及默认入口。

回滚演练使用历史版本隔离脚本完成。V0.3.5 RC1 已撤销，当前项目不再保留候选对比入口。
