# V0.3.0 验证记录

本版验证脚本为`verify-v030.cjs`。它在隔离浏览器上下文中检查标签语义色、紧凑默认宽度与行高、人工/活动原因单行截断及完整 Tooltip、空值与有效0、活动覆盖优先级、刷新持久化、固定分页和V0.2.9入口隔离。

验证前清空的是隔离上下文的localStorage，不影响用户当前浏览器数据。人工拖拽宽度的兼容性通过脚本读取已有宽度优先级和V0.2.9回归入口共同检查。

## 设计检查

- 销售状态、生命周期、库存三类Tag分别使用浅蓝、浅紫、浅琥珀，文字和背景色均不同；类别文字继续保留。
- AI预测、人工预测、活动预测和最终预测行采用30/34/34/38px目标高度，原因说明单行显示，完整文字由悬停或键盘聚焦触发的Tooltip承载。
- 无用户保存宽度时日列为96px、折叠周列为120px、预测线列为96px；读取到已保存值时不覆盖人工调整。
- 人工预测输入0后最终预测显示`0 (人工)`；活动预测输入后覆盖人工值显示`活动`，并在刷新后保留。
- 旧版入口不加载v030资源，避免新样式污染历史版本。

## 运行

```bash
node verify-v030.cjs
```

截图输出到`evidence/v030-*.png`。本原型仍使用本地Mock数据，没有接入真实主数据、预测模型、权限服务或后端持久化。
