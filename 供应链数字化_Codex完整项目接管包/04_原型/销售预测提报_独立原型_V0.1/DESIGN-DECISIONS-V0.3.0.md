# V0.3.0 预测网格密度与原因查看

沿用COMPATIBILITY-BASELINE.md及V0.2.9规则，本轮只调整视觉密度、标签语义色和原因查看方式。附件作为视觉参考：标签颜色承担状态分层，长文本在当前单元格附近通过Ant Design Tooltip查看，不改变表格数据和填报规则。

销售状态采用低饱和蓝色，生命周期采用低饱和紫色，库存预警采用低饱和琥珀色。三类标签仍显示类别文字，颜色只提供辅助识别；不使用高饱和大面积色块。

预测线使用更紧凑的固定间距：AI预测约30px，人工/活动约34px，最终预测约38px；默认日列96px、周列120px，用户已拖拽保存的列宽继续优先。人工和活动原因在单元格内最多显示一行，悬停或键盘聚焦展示完整文本，Tooltip默认向上并自动避让边界。

继续保留空值留空、有效0、活动>人工>AI、来源换行、历史只读、列配置、固定列及十字高亮。旧版入口和本地Mock数据不改写。
