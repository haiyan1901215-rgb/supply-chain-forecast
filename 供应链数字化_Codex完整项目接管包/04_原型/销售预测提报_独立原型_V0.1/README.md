# 销售预测提报 · 独立原型 V0.3.3

这是一次全新起炉灶的 PMC「销售预测提报」原型，不复用旧版销售预测页面的代码和页面结构。

当前使用版为 **V0.3.4-results2**。本迭代修复计划配置与销售填报的预测数据串联，将历史提报记录的销量/预测数值统一为左对齐，让计划配置「预测结果」支持跨历史批次筛选，并修正预测结果批次详情页签与业务主键展示；保留 V0.3.3 的销售提报交互与可回滚历史。V0.3.5 RC1 已撤销并删除，不再提供候选对比入口。

## 运行

直接打开 `index.html` 即可预览。也可以在本目录启动静态服务器：

```bash
python3 -m http.server 8800 --bind 127.0.0.1
```

## 业务边界

销售只维护未来需求曲线。库存、在途、DOI、预计耗尽、预计到货和 SKU 映射均为只读背景；采购数量、PR、供应周期和备货决策留在 PMC 备货计划页面。

## 原型状态

本原型使用前端 Mock 数据，不含后端持久化、真实预测模型、权限服务或 SCM 写回。当前预测输入、原因、操作记录、备注、列偏好及模板存储于当前浏览器的 localStorage，仅供本地演示。历史快照由固定演示数据生成，运行时冻结，非生产历史数据。

商品、颜色编码映射、销售组合组成、历史预测、历史实际、渠道/版本纳入条件及上架时间均为示例，不代表已确认主数据。分页和筛选已按实际记录工作；未接入的全局菜单仍为静态演示。旧版入口保存在同目录 index.v0.1.6.html、index.v0.1.7.html、index.v0.1.8.html、index.v0.1.9.html。

V0.3.3运行需保留整个目录及v033脚本/样式；index.v0.3.2.html保留上一版入口及原资源。vendor依赖固定版本且本地加载，无需npm安装、构建或运行时CDN。标签、分页、原因浮层、工作页签及SKU列表使用官方Ant Design组件；既有预测业务网格及最终预测详情仍为静态HTML实现，不宣称整页完成迁移。SKU详情为本地Mock只读展示，未对接真实商品主数据中心。销售趋势和历史实际销量使用同一Mock来源。
