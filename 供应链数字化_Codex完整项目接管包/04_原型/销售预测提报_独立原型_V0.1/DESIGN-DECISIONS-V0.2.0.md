# V0.2.0 设计决策 · 2026-09-22

## 本轮要求

- 数据数值统一12px、千分位分隔；最终值与来源同字号，来源加括号。
- 最终来源另起一行，数字右边缘与其他数据行对齐。父体编码连续展示，SKC（颜色）后放复制按钮，按钮仅复制SKC；销售负责人固定置于编码之后。
- 国家/站点/平台并入父ASIN行，不再独占站点标题行。
- 列配置仅显示图标，放在数据更新时间右侧；选中字段支持必选保护、同组置顶、移除、拖拽。
- 筛选与列配置使用真实Ant Design组件，不再使用原生select下拉。
- 历史交互围绕“本次填多少、上次对同一天填多少、过去预测与实际是否一致”组织，不要求理解批次视角/目标日期视角。

## 实现决策

- 继续保留固定左侧、日级时间轴、人工拖拽宽度、四条线、周折叠和覆盖优先级。
- 默认顶部只显示“正在填报：2026/10/21”；查看旧提报使用单独的日期选择，切换后明确只读，可一键返回本次填报。
- 点击子体“历史对比”在当前四条线下对齐同一销售日期展示最近两次提报；历史行名明确提报日期；未来实际保持为空。
- 去掉抽象的双视角开关与全局“复盘已发生日期”。改在该子体对比区增加“历史预测与实销核对”：展开独立的过去7天日期区间，明确比较哪次提报，并显示该次AI/人工/活动/最终、实际及偏差，不改变当前填报批次或当前日期窗口。可更改已发生日期范围和对比提报日期。
- 使用React 18与Ant Design 5的官方浏览器分发文件，仅迁移本轮指定的筛选、批次选择、列配置及新增历史核对控件，保留旧业务表格；无依赖安装和工程构建。依赖保存在本地vendor目录，预览无需运行时访问CDN。
- 列配置的置顶/拖拽只作用同一信息组，主图、商品名、预警保持结构固定；所有按钮的实际效果与可操作状态一致。

## 边界

- 历史及实际均为演示数据；实际截至2026/10/20，不能把10/21之后的未来日期伪造为真实销量。
- 当前输入和偏好继续使用本地浏览器存储；保留V0.1.9入口及资源，记录新的V0.2.0版本。
