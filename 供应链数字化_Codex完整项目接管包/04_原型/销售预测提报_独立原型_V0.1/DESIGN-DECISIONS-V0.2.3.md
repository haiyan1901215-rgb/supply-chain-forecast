# V0.2.3 设计决策

- 历史加载控件从商品详情移至最后一个已加载历史批次下方、实际销量上方的固定预测线列。每次追加2批；全部加载后禁用并显示“已加载全部”，可收起回最近2批。按原目标日期对齐，不改变当前窗口。
- TextArea沿用官方showCount，通过公开styles.count接口定位到输入框内部右下角；文本区预留底部计数空间，200字限制、校验和取消行为保留。
- 用户明确要求缩小控件文字，本版本以共享主题12px紧凑字号生成局部主题派生；使用Input/Button/Select等公开token，不修改共享技能主题或覆盖Ant Design内部类。
- 空备注仅保留“备注：”及蓝色笔图标；已有备注文本在前，蓝色编辑按钮在右，不再显示添加备注。
- 四条线上方的控制栏只保留“收起填报”及向上箭头，收起后显示“展开填报”及向下箭头。去掉重复的预测明细文字，入口在可调整列宽内换行，不覆盖边界。
- 固定预测线列使用独立右边界绘制，贯穿控制行、四条预测线、历史及汇总；横向滚动时不被日期背景遮住。
- 保留V0.2.2入口和资源，本版本独立脚本及样式；数据和现有偏好不清空。
