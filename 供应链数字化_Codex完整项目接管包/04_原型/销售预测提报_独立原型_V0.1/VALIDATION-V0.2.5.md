# V0.2.5 验证记录

2026-09-23，使用本机Chrome和Playwright隔离上下文验证，不修改用户已有浏览器填报数据。`verify-v025.cjs`完成本轮交互验证；`verify-v024.cjs`对当前入口完成原有网格回归。页面及控制台错误均为0。

## 新增能力

- SKU与业务识别码分隔符的最终计算样式为“丨”。
- 四个入口均打开同一商品抽屉并定位正确Tab；连续切换SKU映射、商品档案、预测分析、销售趋势后四个页签始终存在。Tab和tabpanel通过Ant Design原生语义关联。
- 实际ECharts实例渲染本期/上期/去年同期三条曲线，图例在图表上方。真实鼠标悬浮显示当前10/17、上期10/10、去年同期2025/10/17的各自销量。
- 七个快捷范围逐一验证：过去7天10/14–10/20；14天10/07–10/20；30天09/21–10/20；本月10/01–10/20；上月09/01–09/30；今年01/01–10/20；去年2025/01/01–12/31。均不纳入模拟今天10/21。
- 通过日历实际选择10/05–10/12后，图表呈现准确8天。今天10/21及未来日期禁选；Esc关闭日历后商品抽屉保留。
- 上期取紧邻等长区间，去年同期按月日映射；2024/02/29无2023对应日时为null。零值计入可比天数，基期为0的变化率为空；无有效配对不产生虚假增减。
- 取消上期只隐藏上期曲线，同期仍保持绿色；切换SKU映射再回销售趋势时，日期及比较开关保持。
- 新品历史同期为空，显示暂无数据、不绘制零线；整个所选区间无任何数据时呈现Empty状态。同ASIN美国/英国记录独立，默认区间与商品身份不串用。
- 关闭/切换商品/尺寸变化均无ECharts生命周期错误；图表宽度随ResizeObserver更新。所有销售图表操作均未改变原有预测窗口、人工值或活动值。
- 1366×768、1440×900、1920×900抽屉无横向溢出；已查看趋势、中文日期弹层、SKU映射、商品档案、缺失同期和悬浮对比截图。
- V0.2.4归档入口不加载v025脚本，旧版仍可打开。

## 设计规范检查

本轮遵循enterprise-product-design-system：新控件使用官方Drawer、Tabs、RangePicker、Radio、Checkbox、Descriptions、Table、Typography、Tag、Image、Empty、Alert及共享ConfigProvider。ECharts为用户明确要求的专业图表组件，比较线使用固定语义颜色。新增样式无!important及.ant-*内部选择器，不修改依赖源码。

Component / Theme / Component Rule / Customization：PASS（本轮新增范围）。Layout / Interaction / State / UX Writing / Responsive / Accessibility / Anti-pattern：PASS（已验证桌面交互与基础语义；不代表完整WCAG审计）。
