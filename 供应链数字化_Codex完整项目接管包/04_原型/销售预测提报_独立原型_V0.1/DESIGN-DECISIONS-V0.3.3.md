# V0.3.3 周标题和原因浮层

2026-09-24：销售页收尾定版与PMC业务扩展见 `PMC-WORKFLOW-DECISIONS.md`。沿用正式V0.3.3销售页，无候选对比；基线清单更新包含新增工作流资源。

依据本轮两项明确要求增量调整；旧版入口与资源归档。

- W周标题只显示ISO周编号及展开/折叠按钮，取消周编号右侧的日期区间。日级表头、周折叠后的下层日期范围及日期选择能力保留。
- 原因Popover仍采用官方白色箭头，移除额外body边框，消除箭头与白色面板衔接处的细线；取消基于整个单元格的向上偏移，恢复直接锚定原因文字上方。
- 预览与编辑复用同一个表单字段渲染函数、控件和字号：人工为预测销量/原因，活动为预测销量/名称/日期/备注。预览呈现已保存值，控件只读，不因悬停修改数据；仍通过现有填报入口进入编辑。
- 保留字符计数与长文滚动。浮层优先向上并依据原因文字上方可用空间限制高度，遇视口边界由Ant Design自动避让，支持键盘聚焦与Esc。
- 空值留空、有效0、活动>人工>AI、手调列宽、统一字体、浅色十字与白色数据面不变。
- 对比V0.3.4 RC1后继续使用正式V0.3.3：仅吸收“编辑浮层不撑高列表、外部收起保留未保存内容、备注保存区不被下一分组遮挡”的交互修复，不采用候选版的悬浮编辑方式。
- 人工预测与活动预测继续从原有单元格入口打开Ant Design Modal；原因/活动信息悬停查看继续使用独立只读Popover，两个入口不复用、不叠加。
- 三个分析入口保持单行显示。
- 字体层级不再沿用“整体缩小一级”策略，改为固定五档：页面/表格一级标题14px/600，商品名称/ASIN等核心信息14px/600，核心指标14px/600，普通业务数据13px/400，辅助信息12px/400，标签文字12px。同一层级只通过颜色和字重表达关系，不再混用多个字号。
- 销量/库存背景指标取消单日销量口径，首两项顺延为7日ADU、14日ADU，避免销售把T+1单日波动误认为本次预测依据。
- 父分组SKC后的颜色名称只作为识别辅助，不作为核心编码处理；“（黑色）”等括号内容使用辅助字号与常规字重，保留SKC编码复制与提示语逻辑。
- 标签层级只保留业务枚举值常驻展示，避免“销售状态：已上架”这类字段名占用商品详情空间；标签类型统一进入Ant Design Tooltip。标签顺序固定为生命周期、价值分档、销量分层。
- 备注编辑属于当前商品详情的内嵌编辑，不新开浮窗；通过提升当前商品单元格层级解决跨分组遮罩，而不是压缩输入框或减少保存动作。
- 原因预览继续与编辑字段保持同源表单样式，但预览态限制文本域行数并隐藏内部滚动；超长内容不撑高表格，点击外部、滚动或Esc关闭。
