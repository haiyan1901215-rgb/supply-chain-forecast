# 项目总览

## 项目目标
围绕供应链领域开展0→1数字化建设，最终形成从需求/预测、计划、采购、生产、质检、入库到库存的可追踪业务链路。

## 当前已知系统
- SCM：已有，主要涉及下单处理，并可将下单内容推送到领星；业务已使用。
- MES：已有外采源码，但使用不足；当前优先Bug修复、微调和推广。
- PMC计划：当前重点，很多计划数据依赖人工表格。
- 面辅料：相关系统能力空白。
- QC：相关系统能力空白。
- 库存：全流程线上数据能力不足。

## 当前已明确的业务主线
销售预测 → FBA过货计划 → 采购计划 → 采购订单 → 生产/采购执行 → QC → 到货/入库 → 库存 → 下一轮计划。

## 当前会议材料中已明确的三表关系
销售预测、FBA过货计划、采购计划是当前供应链计划建设的核心三张表；目标是三者正向、逆向联动。销售预测顺推FBA过货计划，过货缺口逆推采购计划。fileciteturn12file2L523-L541
