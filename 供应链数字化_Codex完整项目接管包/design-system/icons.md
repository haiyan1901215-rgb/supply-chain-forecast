# Icon Registry

默认来源：`@ant-design/icons` 的项目内置浏览器包。禁止 Emoji、图片 Icon、新 IconFont 或第二套 Icon Library。

| 语义 | 注册 Icon / 资产 |
|---|---|
| 搜索 | `SearchOutlined` |
| 设置 / 列配置 / 关系管理 | `SettingOutlined` |
| 更多 | `MoreOutlined` |
| 编辑 | `EditOutlined` |
| 删除 | `DeleteOutlined` |
| 添加 | `PlusOutlined` |
| 刷新 | `ReloadOutlined` |
| 返回 / 前后 | `LeftOutlined` / `RightOutlined` |
| 展开 / 收起业务层级 | `ForecastToggleIcon`，单一有状态组件 |
| 下拉 | `DownOutlined` |
| 警告 | `WarningOutlined` |
| 固定 | `PushpinOutlined` |
| 置顶 | `VerticalAlignTopOutlined` |
| 拖拽 | `HolderOutlined` |
| 锁定 | `LockOutlined` |
| 关闭 | `CloseCircleOutlined` 或 Ant 容器自带 Close |
| 店铺 | `ShopOutlined` |

兼容资产：销售预测历史 Copy、周展开、商品操作 SVG。新代码不得复制 path；应先复用现有共享组件或登记后集中封装。

尺寸：表格内 12-14px，普通按钮 14-16px。Icon Button 必须有 `aria-label`，陌生语义必须有 Tooltip。
