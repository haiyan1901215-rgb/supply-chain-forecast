# Spacing

基础间距：`2 / 4 / 8 / 12 / 16 / 20 / 24 / 32px`。

| 场景 | 规则 |
|---|---|
| 页面主内容 | 横向 16-18px，紧凑工作台可为 12px |
| 筛选容器 | `10px 12px` 或 `12px 14px`，同一页面不可混用 |
| 区块间距 | 8-12px |
| 按钮组 | 8px |
| Icon + 文字 | 4-6px |
| 表格单元格 | 日级矩阵 8px 横向；普通小表 12px 横向 |
| Modal/Drawer Body | 16-20px |

禁止用负 margin 或负字距解决拥挤；应调整布局、列宽或信息层级。
