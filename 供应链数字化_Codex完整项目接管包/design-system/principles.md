# UI 原则

1. 销售预测是历史 Golden Reference，不为迁就新页面反向重做。
2. Design System 是当前正式规则；Golden Reference 与规则冲突时，记录原因后修正规则或实现。
3. Ant Design 是唯一基础组件库，Ant Design Icons 是默认图标库。
4. 复用顺序：现有业务组件 > 共享 Pattern > Ant 组件 > 新建扩展。
5. 页面差异只能来自业务内容、权限或信息密度，不能重新定义同一语义的视觉和交互。
6. Token 优先于页面常量；共享类优先于重复 CSS。
7. 不用截图承载长期规则；截图只用于视觉回归证据。
8. 不为视觉统一修改 API、数据结构、计算优先级或业务流程。
9. 工作台优先保证扫描、比较和重复操作效率，不使用营销式卡片布局。
10. 可访问名称、键盘操作、焦点状态和 Tooltip 是组件合同的一部分。
