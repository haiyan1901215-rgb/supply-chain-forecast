# Colors

## 基础语义

| 语义 | 值 |
|---|---|
| Primary | Ant Theme `#1f6feb`；预测台账历史主色 `#4865f2` 通过语义别名保留 |
| Text | `#172033` |
| Secondary Text | `#69758b` |
| Disabled / Tertiary | `#94a0b4` |
| Border | `#e5eaf2` |
| Strong Border | `#d1d9e7` |
| Page Background | `#eef2f7` |
| Container Background | `#ffffff` |
| Success | `#059669` |
| Warning | `#d97706` |
| Error | `#e11d48` |
| Info | `#1f6feb` |

状态优先使用 Ant Design 的 Tag、Alert、Message 和语义色。除预测矩阵既有规则外，不新增相近灰色或整行状态底色。
