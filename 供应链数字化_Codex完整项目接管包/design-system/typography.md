# Typography

| 场景 | 字号 | 字重 | 说明 |
|---|---:|---:|---|
| 紧凑页面/模块标题、商品名 | 13px | 600 | 工作台主视觉层级 |
| 表格正文、编码、核心数值 | 12px | 400-600 | 默认业务层级 |
| 表头 | 12px | 500 | 日期辅助文本使用 11px |
| 辅助信息、来源、标签 | 11px | 400-500 | 不承载主要操作 |
| Modal/Drawer 标题 | 13-14px | 600 | 不使用页面 Hero 字号 |

规则：

- 字距固定为 `0`。
- 数字使用 `tabular-nums`。
- 颜色表达语义，不能通过任意放大字号制造层级。
- 长编码、商品名默认单行省略，完整值通过 Tooltip 或详情查看。
