# Table Guidelines

## 对齐

| 列类型 | 默认对齐 |
|---|---|
| 文本、编码、描述 | 左 |
| 独立数量、金额、百分比、差异 | 右 |
| 日期/时间 | 左；同一表内保持一致 |
| 状态 | 左，与文字基线对齐 |
| Checkbox / Radio / 尺码 | 中 |
| 操作 | 遵循已有页面 Pattern，默认左 |
| 日级可编辑预测矩阵 | 左，属于 Golden Reference 明确例外 |

表头必须与数据列使用同一 Alignment。

## 预测矩阵

- 双层表头总高 62px。
- 日列默认 72px，周合计 112px。
- 周边界使用 2px 轻分隔。
- `W` 标签与唯一的有状态展开/折叠按钮组成左对齐的连续控件组，按钮紧随标签右侧，不得居中或推到表头单元格边缘；折叠后第二层表头显示该周日期区间。预测线标题使用同一“文字后紧跟状态图标”规则。
- 预测线展开/折叠只允许一个表头级全局开关；父 ASIN、子 ASIN 和单条预测线行内不得重复放置展开/折叠入口。
- 父 ASIN 是聚合行；子 ASIN 展开后规则/人工/活动/最终为独立 `tr`。
- 身份、尺码、上下文使用 `rowspan`，不得把四条预测线塞进同一视觉行。
- 只在日期矩阵显示十字高亮。
- 一次 hover 只允许一个当前行、一个当前列和一个当前格；移入固定业务列或移出矩阵后必须立即清除。
- 规则、人工/活动、最终预测行高依次为 `40px / 54px / 55px`，与 Golden Reference 的计算样式一致。

## 列宽

- 固定语义列提供合理默认值，允许拖拽到内容宽度以下。
- 内容过长时省略，不得通过 `min-width` 阻止用户缩窄。
- 列宽调整支持指针和键盘左右键，步长 8px。

## 文本与数字

- 文本默认单行省略，完整内容通过 Tooltip/详情查看。
- 数字使用千分位、统一小数位和 `tabular-nums`。
- 空预测输入留白；不可用或明确无值场景按业务合同显示 `—`。

## 固定列与操作

- 固定列与普通列使用相同背景 Token。
- 固定区末端使用 1px 强边框，不叠加重阴影。
- 高频编辑入口可在单元格 hover/focus 出现；编辑图标始终占稳定槽位，不覆盖数值。

## 状态

- 无斑马纹。
- 普通行 hover 不染色；预测日期单元格使用十字高亮。
- Empty/Loading/Error 使用 `components.md` 的共享模式。
