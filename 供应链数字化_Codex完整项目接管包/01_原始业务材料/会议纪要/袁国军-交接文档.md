# 1、领星 ERP

## a、FBA 发货：发货计划

[亚马逊运营\-STA发货 SOP](https://v0xsosgslg1.feishu.cn/wiki/HqZfwRSAYixwIpkbDDNcOWg3nMb?fromScene=spaceOverview&sheet=1EAsAF)

目前领星有一个致命的 BUG，发货计划和发货单进行双重库存预占。按照领星的逻辑，一个发货计划下的所有货件要同时生产发货单，才不会出现库存被其他订单预占情况。领星具体扣减库存逻辑如下：【目前领星技术已经着手再修复这个 BUG，具体修复时间还未定，联系邱佳】

### i、US

免配置费的下单要求：件数必须是 5 的倍数。（重量来源“产品管理”的“单品毛重”）

|**数字禁忌**|**优惠建议重量**|**物流要求**|
|---|---|---|
|0～12Kg，<br>19～24Kg，95Kg～120Kg|62～93Kg,＞122Kg|海运\&空运：单箱\>12KG，单货件\>12KG<br>快递：单箱\>10KG，单货件\>21KG|

目前 AMZ 运营创建 STA 任务后，潮洋 WMS 会自动拉取数据，仓库生成波次作业时，如果是“优惠”类型【免入仓配置费】单据，系统自动上传装箱数据\&生成货件。

仓库作业完成后，系统后台更新货件的重量信息。

物流进行合单，生成 FBA 发货单。详见：[仓储\-FBA 货件合单SOP](https://v0xsosgslg1.feishu.cn/wiki/ILAQwQFQ6iZp2RkXiPrcUSY1nRg?fromScene=spaceOverview)

### ii、非 US

整体在领星 ERP 作业完成。

[领星ERP\-发货计划功能介绍](https://www.lingxing.com/help/article/shipmentPlan) \& [领星ERP\-装箱任务功能介绍](https://www.lingxing.com/help/article/packBoxStack)

### iii、异常处理

|**异常描述**|**处理办法**|
|---|---|
|**STA 任务发货 实物SKU 不足或者错误**，需要剔除|STA 任务已下发，潮洋 WMS 还未拣货，为打印 FNSKU 标签和透明计划。则可以废弃波次，重新拉取 STA 任务数据。如果已经打印标签，为了减少仓库作业难度，则进行潮洋 WMS 的数据修复（新STA 编号、Group ID、商品发货数量）。<br>![image\.png](图片和附件/image%203.png)<br>![image\.png](图片和附件/image%205.png)<br>同步取消百世出库单信息（波次下的拣货单）。|
|**STA 任务增加发货商品**|只能在仓库未作业的情况下，废弃波次，重新拉取 STA 任务数据。<br>已打印标签，则不做数据修改。|
|**发货计划 SKU 信息与发货单 SKU 不一致**|发货计划出现换货或者 Listing 匹配关系出现变更。<br>【**处理办法**】：更新 Listing 的匹配关系，发货单创建完成后，再将匹配关系改回新的 SKU|
|**发货商品信息提示不全**|按提示找相关的人员在 SCM 款号档案中维护相应信息|
|**5 个优惠货件中存在某些货件与实际发货数量不一致情况**|由于领星与 AMZ 接口问题，导致生成的货件和装箱数据不一致。<br>【**处理办法**】：需要运营取消 STA，重新生成新的 STA，重新修改潮洋 WMS 中的 STA 编号\&GroupID，然后重新推送装箱数据\&生成货件。|
|**合单提示库存不足**|由于领星发货计划扣减库存逻辑 BUG（提前释放库存），导致发货单存在库存被其他订单预占，创建发货单时库存不足的风险。<br>【**处理办法**】：找到库存不足的 SKU，与预占库存的订单运营沟通，修改订单释放库存。|
|**合单提示SKU 不存在**|更新 Listing 的匹配关系，发货单创建完成后，再将匹配关系改回新的 SKU|

## e、采购入库单

### i、异常处理

- **收货完成同步异常**

潮洋WMS 进行发货单箱唛包裹签收，推送百世 WMS 入库单。

百世 WMS 收货完成，通常在半小时内会同步完成。但是会出现异常同步不成功，这个需要找志超去查看同步服务是否出现异常，再重新同步。

## f、百世库存与领星库存不一致

双方系统库存不一致，（领星＞百世）导致订单实际无法发货。则需要通过在领星做数量调整单，去锁定库存，但是不审批通过，这样就不会推送百世，领星也无法做订单库存预占。

## g、权限

权限注意分：菜单权限、店铺数据权限、仓库数据权限。部分敏感数据权限要注意，尤其是财务相关数据，包含店铺利润相关数据。“产品表现”、“ASIN360”等统计页面。

[款号维护 SOP](https://v0xsosgslg1.feishu.cn/wiki/FwXSwrrRFi4u6UkjcbHc36btnV9?fromScene=spaceOverview)

领星 SKP、SKU 信息来源大部分是 SCM 款号档案。【目前主数据治理进行中】

### i、注意点

- **工序工价**

款号档案中的工序工价是核价的工序，与工厂生产的工序工价不同。分开管理。

- **辅料维护**

领星有单独的辅料管理，与商品管理是分开的，我们没有做区分，所以款号档案有一个写死的逻辑，“包装耗材（K19）”下的款号信息不会同步领星商品信息，所以需要手工到领星的辅料管理里面创建辅料 SKU。

- **颜色、尺码与领星同步（可忽略）**

领星“产品”\-“属性管理”中，“颜色”\&“尺码”，属性值简码与 SCM 颜色、尺码的编码一致。
