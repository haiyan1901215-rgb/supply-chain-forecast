# 供应链数字化_Codex完整项目接管包_V2

## 这是什么
这是把当前供应链0→1项目的：
1. 历史产品分析回复；
2. 当前可获得的原始业务材料；
3. 当前事实、边界和MVP原则；
4. Codex持续工作的规则；
5. 决策日志与待确认清单；
整合到同一个可持续项目目录。

## 最重要的原则
原始材料 > 最新业务确认 > 历史分析 > 产品推断 > 行业常识。

## 当前核心主线
销售预测 → FBA过货计划 → 采购计划 → SCM采购执行 → 生产/MES → QC → 到货/入库 → 库存 → 下一轮计划。

## 注意
“SCM系统新增需求,及优化需求”中很多“系统/AI优化建议”属于需求建议，不等于已经确认的系统边界；Codex必须区分。

“面辅料自动采购计划”“完整品质管理体系”等属于需求材料中的建设设想，Q4是否纳入需要业务确认。

库存部分严禁把历史另一家公司的具体规则当作当前公司事实。
