# 事实 / 规则 / 推断 / 待确认

## FACT
原始会议或业务文件直接明确的内容。

## RULE
业务明确认可、可以指导系统行为的规则。

## INFERENCE
产品经理根据事实推导出的设计判断，必须注明“推断”。

## TBD
业务尚未确认，必须进入访谈清单。

## CONFLICT
新材料与历史结论不一致时，不要静默覆盖。记录：旧结论、新证据、影响、待确认人、最终决策。
