# 第四季度供应链建设实施计划 V1.0

本套内容接续业务蓝图V3.0，聚焦2026年10—12月实施安排，开发人员4名。

## 文件

- `可编辑文件/2026年Q4供应链建设实施计划_4人团队_V1.0.pptx`：10页汇报，文字与路线图为可编辑对象，9页使用原生PPT表格。
- `第四季度计划内容汇报.md`：完整文字稿，可直接复制至飞书或文档。
- `index.html`：本地逐页预览，直接双击打开。
- `预览图片/`：10页高清图片。
- `工作日与资源测算.json`：逐日工作日判定、人日预算、分工与阶段任务。
- `plan-data.mjs`：内容与资源数据源。
- `build.mjs`：生成PPT、图片、文字稿和预览的源码。
- `package-backup.py`：生成UTF-8文件名的完整备份包，不包含临时构建目录。

## 使用口径

年份沿用前文2026年。按国务院已公布安排及中国大陆双休，10月18、11月21、12月23个工作日，共62个。4人全职对应248人日。其中功能建设148、联调质量52、风险预留48。

人日、日期、开发角色组合、试点范围与协同检查点均为建议，不能作为未经团队评审的交付承诺。人员能力及实际投入比例尚待确认。计划默认复用现有基础框架、SCM和MES服务，并获得产品、业务验收及数据接口责任人的支持。未假设专职测试。

节假日来源与业务依据已写入文字稿及PPT备注。原业务方案和V3.0边界说明放在`参考依据/`中，保留本次估算与业务原文的区别。

## 后续更新

优先修改`plan-data.mjs`中的日期、人日、角色及工作包，再同步检查`build.mjs`中的汇报结论。生成器会核验月度总量、人员负荷、工作包合计及阶段工作日。

脚本使用本机的Node.js、Artifact Tool及演示文稿校验工具路径。换机器运行需调整依赖路径。最终PPT校验工具禁止覆盖现有输出，重新生成时请使用新版本文件名和新校验记录路径，保留历史版本。

PPT字体为Microsoft YaHei。不同设备的字体替代可能影响排版。原生表格、文字和形状可直接修改，路线图日期不是自动排程工具。
