# V3.0交付说明

## 使用

- 直接汇报或修改：打开`可编辑文件/Q4供应链系统建设_分层汇报可编辑版_V3.0.pptx`，共10页，16:9。
- 浏览全套图：双击`index.html`，无需联网。
- 插入文档：使用编号01—10的PNG高清图片（3200×1800）。
- 矢量修改：使用同名SVG。PPT中的文字、节点框、线条、箭头也是独立对象；移动节点后需手动调整连线。
- 内容对照：查看`修改落实说明.md`及两份`来源_*.txt`。

## 生成源码

`generate.cjs`生成SVG与PNG；`build-editable.mjs`生成原生可编辑PPTX并验证导出。脚本引用本机运行时和Chrome路径，换设备时需配置Node.js、Playwright、Chrome及Artifact Tool。

旧版V2.0及更早版本保留。完整备份不包含临时构建目录`.build`。
