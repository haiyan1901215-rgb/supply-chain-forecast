# Q4供应链里程碑汇报 V2.0

管理层汇报版，共4页：里程碑总表、阶段与并行关系、交付验收、节假日与资源条件。

## 文件使用

- `可编辑文件/2026年Q4供应链建设里程碑_管理层汇报_V2.0.pptx`：用于信息VP向老板汇报。四页表格均可直接编辑。
- `预览图片/01.png`：一页里程碑总表，可插入其他汇报材料。
- `Q4里程碑汇报.md`：完整文字内容，含交付边界与计划假设。
- `index.html`：本地浏览预览。
- `milestones.mjs`、`里程碑数据.json`：里程碑结构化数据。
- `build.mjs`：生成源码，依赖本机Artifact Tool运行时。重新导出时须使用新的输出与校验记录路径，保留历史文件。
- `参考依据/Q4供应链系统建设.pptx`：用户本次提供的业务方案，未修改。

## 关键口径

建议9月28日启动门户和权限前置建设，10月15日交付门户一期、10月16日完成统一权限底座与首批接入。后续业务从10月19日推进。

这里的“公司级门户/权限”指统一公共能力，一期接入系统清单须先冻结；不表示所有存量系统同时完成改造。复用现有认证和组织人员能力是该短周期成立的前提。

所有日期都是建议目标。4名开发为同一共享资源池，Q4的248理论人日已扣出32人日用于前置底座，剩216人日覆盖业务开发、联调、试点与收尾。9月底的12人日单列为Q3投入。公司休假、兼职或其他项目占用需另扣。

MES沿用附件“已有系统协同接入”的边界。MRP与SCM成衣采购并行。首批场景交付与后续全量扩围区分列示。

原方案以及上一版实施计划均保留。PPT字体为Microsoft YaHei，不同设备字体替代可能影响排版。
