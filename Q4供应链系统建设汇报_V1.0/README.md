## 汇报口径

主链：商品数据准备 → 销售需求 → PMC计划 → 采购执行 → 生产协同 → 入库与库存回流 → 下一轮计划。

PMC为计划中枢，输出采购需求、备货和过货计划，承载审核与人工调整；SCM承接采购执行；MES承接生产执行与进度回传。此职责方向采用本次用户明确要求，MES具体任务来源和回传字段仍需确认。

MRP表示物料需求测算与齐料协同能力，涉及自采或发料订单时适用。BOM、物料主数据、库存与在途是输入，物料需求及齐料状态是交付。尚未确认其独立系统归属，不把完整MRP建设写入Q4交付承诺。

图中的业务先后关系不代表系统串行开发。Q4四条工作流并行：供应链计划MVP、SCM承接评估、MES稳定化、MRP/QC/库存业务域与接口梳理。具体开发范围和验收指标需联评，本图不虚构上线日期、收益数值或完成比例。

数仓读取规则和业务数据，提供系统预测及缺口计算；销售按W周组织、按天填报人工修正与活动影响；PMC进行计划判断。来源库存系统维护库存事实，PMC使用计划库存视图。
